# 🪦 Project Graveyard
Analyze any GitHub user's repos: which died, why, and which dies next.

## Run
```
pip install -r requirements.txt
export GITHUB_TOKEN=ghp_xxx          # optional but recommended (60 -> 5000 req/hr)
export ANTHROPIC_API_KEY=sk-ant-xxx  # optional, enables AI autopsies
streamlit run app.py
```
